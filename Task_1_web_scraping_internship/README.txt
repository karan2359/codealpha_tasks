WEB SCRAPING INTERNSHIP PROJECT
===============================

Project: Book Price Dataset Scraper
Website Scraped: https://books.toscrape.com/
Tools Used: Python, BeautifulSoup4, Requests, Pandas

What I Did:
- Scraped book titles, prices, and ratings from a public website
- Collected data from 3 pages (60 books total)
- Saved data to CSV format for analysis

Dataset: books_dataset.csv
- Contains 60 rows (books)
- Columns: title, price, rating

How to Run:
python scraper.py
